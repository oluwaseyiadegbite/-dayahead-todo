DayAhead — Daily To-Do List

A simple to-do list website for planning the next day and keeping track of everyday tasks.

Why I Created It

I sometimes forget things I need to do during the day, so I built this website to help me stay organised. The evening before, I add the tasks I want to complete tomorrow. When the day comes, I check my list and mark tasks as complete as I go.

This project gives me a practical tool I use myself while helping me develop my HTML, CSS and JavaScript skills.

What It Does

* Adds tasks to a daily to-do list.
* Marks tasks as complete or incomplete when clicked.
* Deletes tasks that are no longer needed.
* Displays the number of unfinished tasks.
* Saves tasks in the browser so they remain after refreshing or reopening the website.

Built With

* HTML for the page structure.
* CSS for the layout and styling.
* JavaScript for task management and user interaction.
* localStorage for saving tasks in the browser.

How to Use

1. Type a task into the input field.
2. Click Add to save it.
3. Click a task to toggle its completion status.
4. Click X to delete it.

Tasks are stored in the browser used to add them. They do not sync between devices, and clearing the website’s browser data removes the saved list.

Run Locally

Download the repository, keep index.html, style.css and script.js together in one folder, and open index.html in a browser.

Skills Practised

* Updating page content using JavaScript and the DOM.
* Handling form submissions and click events.
* Managing task data with arrays and objects.
* Using JSON and localStorage to save and retrieve data.
* Separating structure, styling and behaviour into three files.
